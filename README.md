## Features
- Complete car rental and tourism platform specifically designed for Kanpur, Uttar Pradesh.
- Outstation cabs to Lucknow, Agra, Varanasi, Delhi, Prayagraj, Ayodhya, Jaipur, etc.
- Local hourly car rental (4hr/40km, 8hr/80km, 12hr/120km).
- Airport (Chakeri KNU) and Railway (CNB Central) transfers.
- Sightseeing tours and pilgrimage packages.
- Full admin dashboard for managing bookings, fleet, packages, and inquiries.
- Direct integration with Supabase database with Row Level Security (RLS).
